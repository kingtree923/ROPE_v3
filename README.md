# ROPE 2024 Protocol Viewer

Mobile-friendly static web app for viewing individual protocol pages from the **2024 Region One Protocol Effort (R.O.P.E.) Guidelines**.

## Quick start

### Best way (recommended)
1. Upload this entire folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under “Source”, choose the branch that contains `index.html` (usually `main`) and `/ (root)`.
4. Wait a minute, then open the GitHub Pages URL on your phone.

### Local use
1. Download / unzip the repository.
2. Double-click `index.html` **or** open it in Chrome / Safari / Firefox.
3. The list, search, and category buttons will work immediately.

> **Important:** Do **not** try to use the app by clicking the HTML file inside the GitHub website’s file browser. That preview is sandboxed and JavaScript is disabled. Always use GitHub Pages or open the file locally.

## Features

- Live search by protocol name, category, or page number
- Category filter tabs (Medical, Cardiac, Trauma, Pediatric, HAZMAT, Advanced)
- One-tap open of the exact protocol page image
- Fully responsive (phones, tablets, desktop)
- Pinch-to-zoom on protocol images
- No internet required after first load (works offline)
